## ภาพรวม shadcn/ui & Radix UI Ecosystem

**shadcn/ui** ได้ปฏิวัติวิธีที่นักพัฒนาสร้างหน้าตาของเว็บแอปพลิเคชันยุคใหม่ โดยแหวกแนวจากกรอบเดิมของ Component Libraries ทั่วไป (เช่น Material UI, Ant Design, Chakra UI) ที่มักติดตั้งเป็น NPM Package ขนาดใหญ่ที่ปรับแต่งยาก

ปรัชญาของ shadcn/ui:
> **"Not a component library. It's a collection of re-usable components that you can copy and paste into your apps."**

สถาปัตยกรรม 3 ชั้นอันทรงพลัง:
1. **Radix UI (Headless Layer)**: ควบคุมพฤติกรรม Accessibility (WAI-ARIA compliance, focus trap, keyboard navigation) 100% โดยไม่มีการใส่ Style มาให้เกะกะ
2. **Tailwind CSS v4 (Style Layer)**: ตกแต่งความสวยงามผ่าน Utility Classes และ CSS Variables (`@theme`)
3. **shadcn/ui (Assembly Layer)**: นำทั้งสองชั้นมาประกอบเข้าด้วยกันเป็นไฟล์ TypeScript (`components/ui/*`) วางไว้ในโปรเจกต์ของคุณโดยตรง ทำให้คุณเป็น **"เจ้าของโค้ดอย่างแท้จริง"** มีอิสระในการปรับแต่งได้ทุกบรรทัด
