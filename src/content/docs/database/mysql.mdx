# MySQL 8.x

(เอกสารชุดนี้เจาะลึกระบบจัดการฐานข้อมูลเชิงสัมพันธ์ **MySQL 8.x** ครอบคลุมตั้งแต่สถาปัตยกรรม Storage Engine, กลไก InnoDB, ระบบล็อก, การทำดัชนี, จนถึงการปรับแต่งประสิทธิภาพและ High Availability ระดับ Enterprise)

<Callout type="tip" title="ทำไม MySQL จึงครองส่วนแบ่งฐานข้อมูลเว็บแอปพลิเคชันอันดับหนึ่งของโลก">
MySQL 8 (และ 8.4 LTS) เป็นหัวใจสำคัญของบริษัทยักษ์ใหญ่ระดับโลกอย่าง Meta, GitHub, Uber, YouTube, Shopify และ Netflix ด้วยสถาปัตยกรรม Pluggable Storage Engine อันทรงพลัง โดยเฉพาะเครื่องยนต์ **InnoDB** ที่มี Clustered Index, Row-level Locking, MVCC, และ Crash Recovery ที่เชื่อถือได้สูง ในคู่มือนี้เราจะใช้แพลตฟอร์ม **Smart Butcher Marketplace** (ระบบร้านค้าเนื้อวากิวและเนื้อดรายเอจพรีเมียม) เป็นแกนกลางในการจำลองคำสั่งและวิเคราะห์ปัญหาจริง
</Callout>
