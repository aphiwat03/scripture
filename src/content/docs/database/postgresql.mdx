# PostgreSQL 16

(สำหรับฝั่ง Application และการใช้งาน Prisma Client สามารถดูเพิ่มเติมที่กลุ่ม BACKEND: [Prisma ORM](/docs/backend/prisma-orm) โดยเอกสารนี้จะเจาะลึกที่ตัวฐานข้อมูล PostgreSQL 16 สถาปัตยกรรม ชนิดข้อมูล constraints และการทำงานระดับ engine เป็นหลัก)

<Callout type="tip" title="ทำไม PostgreSQL 16 จึงเป็นหัวใจของระบบ Enterprise Data Platform">
PostgreSQL เป็นระบบจัดการฐานข้อมูลเชิงสัมพันธ์แบบวัตถุ (Object-Relational Database Management System: ORDBMS) ที่ได้รับการยอมรับว่ามีมาตรฐานความถูกต้องของข้อมูล (Data Integrity) สูงที่สุดในโลกโอเพนซอร์ส ในเวอร์ชัน 16 ได้มีการยกเครื่องประสิทธิภาพครั้งใหญ่ ทั้งระบบ Query Parallelism, การประมวลผล Logical Replication จาก Standby Node, การเก็บ Cumulative Statistics ใน Shared Memory, และการปฏิบัติตามมาตรฐาน ANSI SQL เกือบสมบูรณ์แบบ ในคู่มือนี้เราจะใช้แพลตฟอร์ม **Smart Butcher Marketplace** (ร้านค้าเนื้อพรีเมียมและเนื้อดรายเอจออนไลน์) เป็นแกนกลางในการศึกษาโครงสร้างระดับลึก
</Callout>
