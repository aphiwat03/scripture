## ภาพรวม Tailwind CSS v4 & Next.js 16

**Tailwind CSS v4** คือการยกเครื่องสถาปัตยกรรมครั้งใหญ่ที่สุดในประวัติศาสตร์ของ Tailwind โดยเปลี่ยนผ่านจากระบบเดิม (v3 ที่พึ่งพา JavaScript Engine และไฟล์ `tailwind.config.js`) ไปสู่สถาปัตยกรรม **"CSS-First Engine (Oxide Engine)"** ที่เขียนด้วยภาษา Rust ซึ่งมีความเร็วในการคอมไพล์สูงขึ้นกว่าเดิมถึง 10 เท่า

จุดเปลี่ยนสำคัญใน Tailwind CSS v4:
- **Zero Configuration File**: ไม่มีไฟล์ `tailwind.config.js` เป็นค่าเริ่มต้นอีกต่อไป ทุกการตั้งค่าทำผ่าน CSS ดั้งเดิมด้วย Directive `@theme`
- **One-line Import**: นำเข้าเพียง `@import "tailwindcss";` บรรทัดเดียวใน `globals.css` (แทนที่ `@tailwind base; components; utilities;`)
- **Native Modern Features**: รองรับ CSS Variables (`--color-*`), ระบบสีสเปกตรัมกว้าง **OKLCH**, Container Queries (`@container`), 3D Transforms, และ Relational Variants (`has-*`, `not-*`) ในตัวทันที
- **Automatic Content Detection**: ไม่ต้องระบุพาธ `content: [...]` อีกต่อไป เอนจินจะสแกนไฟล์เทมเพลตและคอมโพเนนต์ในโปรเจกต์ให้อัตโนมัติ
