# Testing Fundamentals

(สำหรับเครื่องมือทดสอบเฉพาะทาง สามารถดูเพิ่มเติมได้ที่ [Jest](/docs/testing/jest), [Backend Testing](/docs/testing/backend-testing), [Frontend Testing](/docs/testing/frontend-testing), และ [E2E Testing](/docs/testing/playwright) โดยเอกสารนี้จะปูพื้นฐานแนวคิด หลักการสากล และกลยุทธ์การทดสอบซอฟต์แวร์ระดับองค์กร)

| หัวข้อในบทเรียนนี้ | ขอบเขตเนื้อหาสำคัญ | ลิงก์ข้ามไปยังหัวข้อ |
| :--- | :--- | :--- |
| **1. Cost of Bugs** | ทำไมต้องเขียนเทสต์ และต้นทุนของ Bug ที่หลุดไปถึง Production | [อ่านหัวข้อที่ 1](/docs/testing/fundamentals/cost-of-bugs) |
| **2. Pyramid & Trophy** | เปรียบเทียบ Testing Pyramid และ Testing Trophy (Unit / Integration / E2E) | [อ่านหัวข้อที่ 2](/docs/testing/fundamentals/testing-pyramid) |
| **3. AAA & Behavior** | โครงสร้าง Arrange-Act-Assert และการเทสต์พฤติกรรมแทนรายละเอียดภายใน | [อ่านหัวข้อที่ 3](/docs/testing/fundamentals/aaa-pattern) |
| **4. Test Doubles** | ความต่างของ Dummy, Stub, Spy, Mock และ Fake พร้อมตัวอย่างจริง | [อ่านหัวข้อที่ 4](/docs/testing/fundamentals/test-doubles) |
| **5. TDD Workflow** | วงจร Red-Green-Refactor และการประยุกต์ใช้ในงานจริง | [อ่านหัวข้อที่ 5](/docs/testing/fundamentals/tdd-workflow) |
| **6. Code Coverage** | Line vs Branch Coverage และทำไม 100% Coverage จึงไม่ใช่เป้าหมายสูงสุด | [อ่านหัวข้อที่ 6](/docs/testing/fundamentals/code-coverage) |
| **7. What to Test** | เกณฑ์ตัดสินใจเลือกสิ่งที่ควรเทสต์เน้นๆ และสิ่งที่ไม่ควรเสียเวลาเทสต์ | [อ่านหัวข้อที่ 7](/docs/testing/fundamentals/what-to-test) |
| **8. Flaky Tests** | สาเหตุของเทสต์ที่เดี๋ยวผ่านเดี๋ยวพัง และวิธีป้องกันอย่างถาวร | [อ่านหัวข้อที่ 8](/docs/testing/fundamentals/flaky-tests) |
