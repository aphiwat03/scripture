คู่มือเชิงลึกสำหรับการสืบสวนและค้นหาต้นตอของบั๊กระดับ Production ด้วย **VS Code Debugger**, **Node.js V8 Inspector (NestJS 11)**, **Next.js 16 Debugging**, **Test-Driven Bug Reproduction**, **Structured JSON Logging** และการตรวจสอบช่องโหว่ความปลอดภัยด้วย **npm audit**
