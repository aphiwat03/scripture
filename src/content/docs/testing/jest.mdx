# Jest

(สำหรับเทสต์เฉพาะทางของ NestJS, React Testing Library และ Playwright สามารถดูเพิ่มเติมได้ที่ [Backend Testing](/docs/testing/backend-testing), [Frontend Testing](/docs/testing/frontend-testing) และ [E2E Testing](/docs/testing/playwright) โดยเอกสารนี้จะเจาะลึกที่แกนหลัก เครื่องมือคำสั่ง matchers, mocking และ configuration ของ Jest เป็นฐานราก)

<Callout type="tip" title="ทำไม Jest จึงเป็นมาตรฐานทองคำของการทดสอบระดับ Enterprise">
Jest คือ Testing Framework ที่ทรงอิทธิพลและถูกนำไปใช้งานมากที่สุดในระบบนิเวศ JavaScript และ TypeScript ด้วยปรัชญา **"Delightful JavaScript Testing"** ที่มอบชุดเครื่องมือครบวงจรแบบ All-in-One ในตัว (Test Runner, Assertion Library, Mocking Engine, Fake Timers, Snapshot Serialization และ Code Coverage) โดยไม่ต้องติดตั้งไลบรารีเสริมแยกชิ้น ในเอกสารฉบับนี้ เราจะศึกษาแกนหลักของ Jest 29.x ผ่านแพลตฟอร์มจำลองระดับโปรดักชัน **"Smart Butcher Marketplace"** (แพลตฟอร์มสั่งซื้อเนื้อสัตว์เกรดพรีเมียมและเนื้อบ่มดรายเอจออนไลน์) เพื่อทำความเข้าใจพฤติกรรมระดับ Engine และการเขียนชุดทดสอบที่แม่นยำ ปราศจาก Flaky Tests
</Callout>
