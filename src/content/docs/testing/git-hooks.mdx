คู่มือการวางระบบ **Automated Quality Gates** บนเครื่องของนักพัฒนาด้วย **Husky v9**, **lint-staged** และ **Commitlint (Conventional Commits)** เพื่อรับประกันว่าเฉพาะโค้ดที่ผ่านการทดสอบและจัดรูปแบบเรียบร้อยแล้วเท่านั้นจึงจะสามารถ Commit เข้าสู่ Git ได้

| 1 | **Husky lint-staged** | เจาะลึกเนื้อหาและสถาปัตยกรรมของ Husky lint-staged พร้อมโค้ดตัวอย่างและการประยุกต์ใช้งานจริง | [เปิดอ่าน Husky lint-staged](/docs/testing/git-hooks/husky-lint-staged) |
| 2 | **Commit Standard** | เจาะลึกเนื้อหาและสถาปัตยกรรมของ Commit Standard พร้อมโค้ดตัวอย่างและการประยุกต์ใช้งานจริง | [เปิดอ่าน Commit Standard](/docs/testing/git-hooks/commit-standard) |
