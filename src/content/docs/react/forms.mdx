## 1. แนวคิด (Concept)

การจัดการฟอร์มใน React มี 2 ปรัชญาหลัก:
- **Controlled Components**: React State เป็นผู้ควบคุมค่าในช่องพิมพ์ 100% (ทุกตัวอักษรที่พิมพ์จะกระตุ้น `onChange` และอัปเดต State) เปรียบเหมือน "คนขับที่ต้องคุมพวงมาลัยทุกองศา"
- **Uncontrolled Components**: DOM ดั้งเดิมของเบราว์เซอร์เป็นผู้เก็บค่าไว้เอง และ React จะแอบไปอ่านค่าผ่าน `useRef` หรือ `FormData` ตอนกดปุ่ม Submit เท่านั้น เปรียบเหมือน "รถยนต์ไร้คนขับที่ไปตรวจเช็คตอนถึงปลายทาง"

---

## 2. เปรียบเทียบ Controlled vs Uncontrolled vs React Hook Form

| คุณสมบัติ | Controlled Component (`useState`) | Uncontrolled Component (`useRef`) | React Hook Form + Zod |
| :--- | :--- | :--- | :--- |
| **จำนวน Re-render** | Re-render **ทุกครั้งที่กดพิมพ์** 1 ตัวอักษร | **ไม่ Re-render** ขณะพิมพ์ | **ไม่ Re-render** (ใช้ Uncontrolled ภายใน) |
| **Real-time Validation** | ทำได้ง่ายมากในตัว | ทำได้ยาก | รองรับ Real-time และ Schema validation |
| **ขนาดและประสิทธิภาพ** | หน่วงเมื่อฟอร์มมีมากกว่า 20 ช่อง | เร็วมาก แต่เขียนโค้ดยาว | เร็วมากที่สุดและโค้ดกระชับ |

## 3. ตัวอย่างโค้ด (TypeScript)

### ตัวอย่างที่ 1: Controlled Component พื้นฐาน

```tsx filename="components/SimpleControlledForm.tsx"
'use client';

import React, { useState } from 'react';

export function SimpleControlledForm() {
  const [email, setEmail] = useState('');

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    alert(`ส่งข้อมูล: ${email}`);
  };

  return (
    <form onSubmit={handleSubmit} className="space-y-3">
      <input
        type="email"
        value={email} // ผูกค่ากับ State
        onChange={(e) => setEmail(e.target.value)} // อัปเดตทุกครั้งที่พิมพ์
        placeholder="กรอกอีเมล"
        className="px-3 py-1.5 border rounded-lg text-sm"
      />
      <button type="submit" className="px-3 py-1.5 bg-accent text-white rounded-lg text-xs">
        ส่ง
      </button>
    </form>
  );
}
```

### ตัวอย่างที่ 2: Modern Form ด้วย React Hook Form และ Zod

```tsx filename="components/AdvancedProfileForm.tsx"
'use client';

import React from 'react';
import { useForm } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';
import { z } from 'zod';

const profileSchema = z.object({
  username: z.string().min(3, 'ชื่อผู้ใช้ต้องมีอย่างน้อย 3 ตัวอักษร'),
  age: z.number({ invalid_type_error: 'กรุณากรอกตัวเลข' }).min(18, 'ต้องมีอายุ 18 ปีขึ้นไป'),
});

type ProfileInput = z.infer<typeof profileSchema>;

export function AdvancedProfileForm() {
  const {
    register,
    handleSubmit,
    formState: { errors, isSubmitting },
  } = useForm<ProfileInput>({
    resolver: zodResolver(profileSchema),
  });

  const onSubmit = async (data: ProfileInput) => {
    console.log('ข้อมูลถูกต้อง:', data);
  };

  return (
    <form onSubmit={handleSubmit(onSubmit)} className="space-y-4 max-w-sm">
      <div>
        <label className="text-xs font-semibold">Username</label>
        <input {...register('username')} className="w-full p-2 border rounded" />
        {errors.username && <p className="text-red-500 text-xs mt-1">{errors.username.message}</p>}
      </div>

      <div>
        <label className="text-xs font-semibold">Age</label>
        <input {...register('age', { valueAsNumber: true })} type="number" className="w-full p-2 border rounded" />
        {errors.age && <p className="text-red-500 text-xs mt-1">{errors.age.message}</p>}
      </div>

      <button type="submit" disabled={isSubmitting} className="w-full py-2 bg-blue-600 text-white rounded">
        บันทึกข้อมูล
      </button>
    </form>
  );
}
```

## 4. ควรใช้เมื่อไหร่ / ไม่ควรใช้เมื่อไหร่

- **Controlled (`useState`)**: ใช้กับฟอร์มสั้นๆ 1-2 ช่องพิมพ์ เช่น ช่องค้นหาด่วน
- **React Hook Form + Zod**: ใช้เป็น **มาตรฐานหลัก** สำหรับฟอร์มในระบบจริงทุกประเภท เพราะประสิทธิภาพสูงสุดและ Type-safe ครบวงจร

## 5. คำถามสัมภาษณ์งาน (Interview Questions)

### Q1: Controlled Component กับ Uncontrolled Component ต่างกันอย่างไร และอะไรให้ประสิทธิภาพดีกว่ากัน?
**แนวทางคำตอบ**: Controlled Component เก็บค่าไว้ใน React State ทำให้เกิด Re-render ทุกครั้งที่มีการกดพิมพ์คีย์บอร์ด เหมาะสำหรับการทำ Real-time Formatting ส่วน Uncontrolled Component ให้ DOM เป็นผู้เก็บค่าและอ่านค่าผ่าน Ref เฉพาะตอน Submit ซึ่งให้ประสิทธิภาพสูงกว่าอย่างชัดเจนในฟอร์มขนาดใหญ่
