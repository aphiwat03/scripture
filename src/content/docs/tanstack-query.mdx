## ภาพรวม TanStack Query v5 & Server State Management

**TanStack Query (เดิมชื่อ React Query)** คือไลบรารีระดับมาตรฐานอุตสาหกรรมสำหรับการจัดการ **"Server State"** ในเว็บแอปพลิเคชันยุคใหม่

หลายคนเข้าใจผิดว่า TanStack Query คือไลบรารีสำหรับดึงข้อมูล (Data Fetching Library) เช่นเดียวกับ `fetch` หรือ `axios` แต่ในความเป็นจริง TanStack Query คือ **"Async State Manager & Smart Caching Engine"** ที่ทำหน้าที่:
- ขจัดปัญหา **Race Conditions** เมื่อผู้ใช้พิมพ์ค้นหาอย่างรวดเร็ว
- จัดการสถานะ **Loading, Error, Success** ให้โดยอัตโนมัติ 100%
- ทำ **Deduplication** (รวมคำขอ API ที่ซ้ำซ้อนให้ยิงเพียงครั้งเดียว)
- ทำ **Background Refetching** ดึงข้อมูลสดใหม่ทันทีเมื่อสลับหน้าต่างกลับมา (`refetchOnWindowFocus`) หรือเครือข่ายต่อติดใหม่ (`refetchOnReconnect`)
- จัดการ **Cache Invalidation** และ **Optimistic Updates** (อัปเดตหน้าจอทันทีก่อนที่เซิร์ฟเวอร์จะตอบกลับ)
