## ภาพรวม Zustand v5 & Client State Management

**Zustand (ภาษาเยอรมันแปลว่า "สถานะ/State")** คือไลบรารีจัดการ State ฝั่ง Client ยอดนิยมอันดับ 1 สำหรับ React และ Next.js ในปัจจุบัน ด้วยความเรียบง่าย ขนาดไฟล์ที่เล็กจิ๋ว (น้อยกว่า 1.5 KB) และประสิทธิภาพในการป้องกันการ Re-render ที่เหนือกว่า Context API และ Redux Toolkit อย่างเทียบไม่ติด

ความแตกต่างสำคัญใน **Zustand v5**:
- พัฒนาบนพื้นฐานของ React 18/19 **`useSyncExternalStore`** อย่างสมบูรณ์แบบ กำจัดปัญหา State Tearing ใน Concurrent Rendering
- ปรับปรุง Type Inference ของ TypeScript ให้กระชับขึ้นด้วยรูปแบบ `create<State>()((set, get) => ...)`
- การเปรียบเทียบค่าความเปลี่ยนแปลงใน Selector ใช้ **Object Identity (`===`)** เป็นค่าเริ่มต้น หากคืนค่า Object หรือ Array ใหม่ ต้องใช้ Hook **`useShallow`** เพื่อป้องกันอาการ Infinite Re-render Loop
- สถาปัตยกรรม SSR-safe สำหรับ Next.js App Router เพื่อไม่ให้ State รั่วไหลข้ามคำขอของผู้ใช้ (Isolation per request)
