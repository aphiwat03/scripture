## 1. แนวคิด (Concept)

การจัดการช่องอัปโหลดไฟล์ (File Upload) ในแบบฟอร์มของโมเดิร์นเว็บแอปพลิเคชันมีความแตกต่างจาก Text Input ทั่วไปอย่างสิ้นเชิง เนื่องจากเบราว์เซอร์ออกแบบให้ `<input type="file" />` เป็น **Read-only Uncontrolled DOM Element** เพื่อความปลอดภัยของระบบไฟล์ในเครื่องผู้ใช้งาน (JavaScript ไม่สามารถเขียนค่า Path หรือยัด File เข้าไปตรงๆ ได้)

ในงานระดับมืออาชีพ ผู้ใช้งานมักต้องการประสบการณ์ที่ลื่นไหลกว่าช่องเลือกไฟล์แบบเดิม:
1. **Drag-and-Drop Dropzone**: สามารถลากไฟล์ภาพหรือเอกสารมาปล่อยลงบนพื้นที่ได้ทันที
2. **Instant Visual Preview**: แสดงภาพตัวอย่างทันทีก่อนจะทำการอัปโหลดจริงขึ้นเซิร์ฟเวอร์
3. **Comprehensive Client-side Validation**: ตรวจสอบขนาดไฟล์ (File Size) และประเภทไฟล์ (MIME Type) ด้วย **Zod v4** ตั้งแต่ก่อนส่งคำขอ Network
4. **Multipart FormData Transmission**: แปลงข้อมูลทั้งข้อความและ Binary Files รวมกันส่งไปยัง Backend API (เช่น NestJS Multer หรือ Fastify Multipart)

เพื่อประสานประสบการณ์เหล่านี้เข้าด้วยกันอย่างราบรื่น เราจะใช้ **`Controller`** เพื่อผูก Dropzone เข้ากับ React Hook Form และใช้ Web API อย่าง **`URL.createObjectURL`** ควบคู่กับกลไก **Memory Cleanup (`URL.revokeObjectURL`)** เพื่อป้องกันปัญหา Memory Leak

## 2. หลักการเบื้องหลัง (Under the Hood)

### 2.1 ทำไมการใช้ `register` กับ Native File Input ถึงมีข้อจำกัด?

เมื่อใช้ `register('avatar')` กับ Native `<input type="file" />`:
- ค่าที่ RHF เก็บจะเป็น **`FileList`** ซึ่งเป็น FileList Object ไม่ใช่ JavaScript Array
- หากต้องการเข้าถึงไฟล์ตัวแรก ต้องอ่านจาก `fileList[0]`
- หากผู้ใช้กดยกเลิก หรือต้องการทำ Dropzone แบบ Drag-and-Drop การจัดการ State ผ่าน `register` จะทำได้ยากมาก

ดังนั้น สำหรับ Custom Dropzone หรือช่องอัปโหลดภาพ การใช้ **`Controller`** และเก็บ State เป็น **`File | null`** หรือ **`File[]`** โดยตรง จะทำให้การเขียน Zod Schema สวยงาม ปลอดภัย และมี Type ชัดเจนกว่ามาก

### 2.2 โครงสร้างการ Validate ไฟล์ด้วย Zod v4

ในเบราว์เซอร์ ไฟล์ทุกไฟล์จะสืบทอดมาจากคลาส **`File`** (ซึ่งต่อยอดมาจาก `Blob`):

```typescript
const MAX_FILE_SIZE = 5 * 1024 * 1024; // 5MB in Bytes
const ACCEPTED_IMAGE_TYPES = ['image/jpeg', 'image/png', 'image/webp'];

const fileSchema = z
  .custom<File>((val) => val instanceof File, 'กรุณาเลือกไฟล์เอกสาร')
  .refine((file) => file.size <= MAX_FILE_SIZE, 'ขนาดไฟล์ต้องไม่เกิน 5MB')
  .refine(
    (file) => ACCEPTED_IMAGE_TYPES.includes(file.type),
    'รองรับเฉพาะไฟล์รูปภาพนามสกุล .jpg, .png และ .webp เท่านั้น'
  );
```

### 2.3 วงจรชีวิตของ Browser Blob URL และปัญหา Memory Leak

เมื่อต้องการแสดงภาพตัวอย่าง (Preview) เรามักเรียก:

```typescript
const previewUrl = URL.createObjectURL(file);
```

#### ⚠️ กับดัก Memory Leak:
ฟังก์ชัน `URL.createObjectURL()` จะสร้างสตริงชี้ (Internal Pointer) ไปยัง Memory Buffer ใน RAM ของเบราว์เซอร์ **ซึ่ง Garbage Collector ไม่สามารถเก็บกวาดทิ้งได้ด้วยตนเอง** แม้ว่าคอมโพเนนต์จะถูกทำลายไปแล้ว!

หากผู้ใช้เลือกไฟล์ใหม่เรื่อยๆ หรือเปิดปิดหน้าเว็บนี้บ่อยๆ หน่วยความจำ RAM จะพุ่งสูงขึ้นเรื่อยๆ เราจึง **ต้องเรียก `URL.revokeObjectURL(previewUrl)` ทุกครั้งที่**:
1. ผู้ใช้เปลี่ยนไฟล์ใหม่ (ลบ URL ของรูปเก่าทิ้ง)
2. ผู้ใช้กดลบรูปภาพออกจากฟอร์ม
3. คอมโพเนนต์ Unmount ออกจาก DOM (ใน Cleanup Function ของ `useEffect`)

## 3. ตัวอย่างโค้ด (TypeScript / TSX)

ตัวอย่างระบบอัปโหลดเอกสารรับรองบริษัทและตราสัญลักษณ์นิติบุคคล (`CompanyKycUploadForm.tsx`) ที่ผสาน Drag-and-Drop Dropzone, Zod v4 File Validation, Object URL Preview พร้อม Memory Cleanup และการส่งข้อมูลเป็น `FormData` ไปยัง NestJS Backend:

```tsx filename="src/features/kyc/components/CompanyKycUploadForm.tsx"
'use client';

import React, { useState, useEffect, useRef } from 'react';
import { useForm, Controller } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';
import { z } from 'zod';
import { UploadCloud, X, FileCheck, AlertCircle, Loader2 } from 'lucide-react';

// ==========================================
// 1. Zod v4 Validation Rules
// ==========================================
const MAX_FILE_SIZE = 5 * 1024 * 1024; // 5MB
const ACCEPTED_IMAGE_TYPES = ['image/jpeg', 'image/png', 'image/webp'];

export const companyKycSchema = z.object({
  companyRegistrationNumber: z
    .string()
    .regex(/^\d{13}$/, 'เลขทะเบียนนิติบุคคลต้องเป็นตัวเลข 13 หลัก'),
  authorizedPersonName: z.string().min(2, 'ต้องระบุชื่อผู้มีอำนาจลงนาม'),
  companyLogo: z
    .custom<File>((val) => typeof window !== 'undefined' && val instanceof File, {
      message: 'กรุณาอัปโหลดรูปภาพตราสัญลักษณ์บริษัท (Logo)',
    })
    .refine((file) => file.size <= MAX_FILE_SIZE, 'ขนาดไฟล์ภาพต้องไม่เกิน 5MB')
    .refine(
      (file) => ACCEPTED_IMAGE_TYPES.includes(file.type),
      'รูปแบบไฟล์ไม่ถูกต้อง รองรับเฉพาะ .jpg, .png และ .webp'
    ),
});

export type CompanyKycInput = z.infer<typeof companyKycSchema>;

// ==========================================
// 2. Custom Dropzone Component พร้อม Preview & Memory Cleanup
// ==========================================
interface ImageDropzoneProps {
  value: File | null;
  onChange: (file: File | null) => void;
  error?: string;
  disabled?: boolean;
}

function ImageDropzone({ value, onChange, error, disabled }: ImageDropzoneProps) {
  const [previewUrl, setPreviewUrl] = useState<string | null>(null);
  const [isDragOver, setIsDragOver] = useState(false);
  const fileInputRef = useRef<HTMLInputElement | null>(null);

  // จัดการวงจรชีวิตของ Object URL เพื่อป้องกัน Memory Leak 100%
  useEffect(() => {
    if (!value) {
      setPreviewUrl(null);
      return;
    }

    const objectUrl = URL.createObjectURL(value);
    setPreviewUrl(objectUrl);

    // Cleanup ทันทีเมื่อ value เปลี่ยน หรือเมื่อ Unmount
    return () => {
      URL.revokeObjectURL(objectUrl);
    };
  }, [value]);

  const handleDrop = (e: React.DragEvent<HTMLDivElement>) => {
    e.preventDefault();
    setIsDragOver(false);
    if (disabled) return;

    if (e.dataTransfer.files && e.dataTransfer.files[0]) {
      onChange(e.dataTransfer.files[0]);
    }
  };

  const handleFileSelect = (e: React.ChangeEvent<HTMLInputElement>) => {
    if (e.target.files && e.target.files[0]) {
      onChange(e.target.files[0]);
    }
  };

  const handleRemove = (e: React.MouseEvent) => {
    e.stopPropagation();
    onChange(null);
    if (fileInputRef.current) fileInputRef.current.value = '';
  };

  return (
    <div className="space-y-2">
      <div
        onDragOver={(e) => { e.preventDefault(); setIsDragOver(true); }}
        onDragLeave={() => setIsDragOver(false)}
        onDrop={handleDrop}
        onClick={() => !disabled && !value && fileInputRef.current?.click()}
        className={`relative flex flex-col items-center justify-center p-6 border-2 border-dashed rounded-xl transition-all cursor-pointer ${
          isDragOver
            ? 'border-blue-500 bg-blue-50/50 dark:bg-blue-950/20'
            : error
            ? 'border-red-300 bg-red-50/20 dark:bg-red-950/10'
            : 'border-slate-300 dark:border-slate-700 hover:border-slate-400 bg-slate-50/50 dark:bg-slate-800/20'
        } ${disabled ? 'opacity-50 cursor-not-allowed' : ''}`}
      >
        <input
          ref={fileInputRef}
          type="file"
          accept={ACCEPTED_IMAGE_TYPES.join(',')}
          className="hidden"
          disabled={disabled}
          onChange={handleFileSelect}
        />

        {previewUrl && value ? (
          <div className="relative group w-full flex flex-col items-center">
            <div className="relative w-40 h-40 rounded-lg overflow-hidden border shadow-sm bg-white dark:bg-slate-900">
              <img
                src={previewUrl}
                alt="Logo Preview"
                className="w-full h-full object-contain p-2"
              />
              <button
                type="button"
                onClick={handleRemove}
                disabled={disabled}
                className="absolute top-2 right-2 p-1 bg-red-600 text-white rounded-full hover:bg-red-700 transition-colors shadow-md"
                title="ลบรูปภาพ"
              >
                <X className="w-4 h-4" />
              </button>
            </div>
            <p className="mt-2 text-xs font-medium text-slate-600 dark:text-slate-300">
              {value.name} ({(value.size / (1024 * 1024)).toFixed(2)} MB)
            </p>
          </div>
        ) : (
          <div className="text-center space-y-2">
            <div className="mx-auto w-12 h-12 flex items-center justify-center rounded-full bg-blue-50 dark:bg-blue-950 text-blue-600">
              <UploadCloud className="w-6 h-6" />
            </div>
            <div className="text-sm">
              <span className="font-semibold text-blue-600 hover:underline">คลิกเพื่อเลือกไฟล์</span> หรือลากไฟล์มาวางที่นี่
            </div>
            <p className="text-xs text-slate-400">
              รองรับ PNG, JPG หรือ WEBP (ขนาดไม่เกิน 5MB)
            </p>
          </div>
        )}
      </div>

      {error && (
        <div className="flex items-center space-x-1.5 text-xs text-red-500">
          <AlertCircle className="w-3.5 h-3.5" />
          <span>{error}</span>
        </div>
      )}
    </div>
  );
}

// ==========================================
// 3. Main KYC Form Component
// ==========================================
export function CompanyKycUploadForm() {
  const {
    register,
    control,
    handleSubmit,
    reset,
    formState: { errors, isSubmitting },
  } = useForm<CompanyKycInput>({
    resolver: zodResolver(companyKycSchema),
    defaultValues: {
      companyRegistrationNumber: '',
      authorizedPersonName: '',
      companyLogo: undefined,
    },
    mode: 'onTouched',
  });

  const onSubmit = async (values: CompanyKycInput) => {
    try {
      // 1. แปลงข้อมูลทั้งหมดเป็น Multipart FormData
      const formData = new FormData();
      formData.append('companyRegistrationNumber', values.companyRegistrationNumber);
      formData.append('authorizedPersonName', values.authorizedPersonName);
      formData.append('logo', values.companyLogo); // Binary File Blob

      // 2. ส่งไปยัง Backend API (เช่น NestJS FileInterceptor / Multer)
      const res = await fetch('/api/v1/companies/kyc', {
        method: 'POST',
        // ⚠️ ข้อสำคัญ: ห้ามใส่ 'Content-Type': 'multipart/form-data' เองเด็ดขาด!
        // ปล่อยให้เบราว์เซอร์เติม Header พร้อม Boundary อัตโนมัติ
        body: formData,
      });

      if (!res.ok) {
        throw new Error('การอัปโหลดเอกสารล้มเหลว กรุณาลองใหม่อีกครั้ง');
      }

      alert('อัปโหลดเอกสารยืนยันตัวตนสำเร็จ!');
      reset();
    } catch (err: any) {
      alert(err.message || 'เกิดข้อผิดพลาดในการเชื่อมต่อเซิร์ฟเวอร์');
    }
  };

  return (
    <div className="max-w-xl mx-auto p-6 bg-white dark:bg-slate-900 border border-slate-200 dark:border-slate-800 rounded-2xl shadow-lg space-y-6">
      <div className="flex items-center space-x-3 border-b pb-4">
        <div className="p-2 bg-emerald-50 dark:bg-emerald-950 text-emerald-600 rounded-lg">
          <FileCheck className="w-6 h-6" />
        </div>
        <div>
          <h2 className="text-lg font-bold text-slate-900 dark:text-white">ยืนยันตัวตนองค์กร (Corporate KYC)</h2>
          <p className="text-xs text-slate-500">อัปโหลดตราสัญลักษณ์และข้อมูลจดทะเบียนของบริษัท</p>
        </div>
      </div>

      <form onSubmit={handleSubmit(onSubmit)} className="space-y-4">
        {/* Registration Number */}
        <div>
          <label className="text-xs font-semibold text-slate-700 dark:text-slate-300">
            เลขทะเบียนนิติบุคคล 13 หลัก *
          </label>
          <input
            {...register('companyRegistrationNumber')}
            placeholder="0105559012345"
            maxLength={13}
            disabled={isSubmitting}
            className="w-full mt-1 px-3 py-2 text-sm border rounded-md dark:bg-slate-800 font-mono"
          />
          {errors.companyRegistrationNumber && (
            <p className="text-xs text-red-500 mt-1">{errors.companyRegistrationNumber.message}</p>
          )}
        </div>

        {/* Authorized Person */}
        <div>
          <label className="text-xs font-semibold text-slate-700 dark:text-slate-300">
            ชื่อกรรมการผู้มีอำนาจลงนาม *
          </label>
          <input
            {...register('authorizedPersonName')}
            placeholder="นายสมชาย มั่นคง"
            disabled={isSubmitting}
            className="w-full mt-1 px-3 py-2 text-sm border rounded-md dark:bg-slate-800"
          />
          {errors.authorizedPersonName && (
            <p className="text-xs text-red-500 mt-1">{errors.authorizedPersonName.message}</p>
          )}
        </div>

        {/* Custom Dropzone via Controller */}
        <div>
          <label className="text-xs font-semibold text-slate-700 dark:text-slate-300 mb-1 block">
            ตราสัญลักษณ์บริษัท (Official Logo) *
          </label>
          <Controller
            control={control}
            name="companyLogo"
            render={({ field, fieldState: { error } }) => (
              <ImageDropzone
                value={field.value}
                onChange={field.onChange}
                error={error?.message}
                disabled={isSubmitting}
              />
            )}
          />
        </div>

        {/* Submit Button */}
        <button
          type="submit"
          disabled={isSubmitting}
          className="w-full py-2.5 px-4 text-sm font-semibold text-white bg-blue-600 rounded-lg hover:bg-blue-700 disabled:opacity-50 flex items-center justify-center space-x-2 transition-all shadow-md"
        >
          {isSubmitting ? (
            <>
              <Loader2 className="w-4 h-4 animate-spin" />
              <span>กำลังแปลงไฟล์และอัปโหลดข้อมูล...</span>
            </>
          ) : (
            <span>ส่งเอกสารยืนยันตัวตน</span>
          )}
        </button>
      </form>
    </div>
  );
}
```

## 4. เทียบกับวิธีเดิม

| มิติการเปรียบเทียบ | วิธีเดิม: ใช้ Native `<input type="file">` ร่วมกับ `useState` | วิธีโมเดิร์น: ใช้ `Controller` + Zod + Drag & Drop |
| :--- | :--- | :--- |
| **การจัดการ Memory** | เรียก `URL.createObjectURL` ค้างไว้ ไม่เคยเรียก `revokeObjectURL` ทำให้ RAM บวม | มี Cleanup Hook เรียก `URL.revokeObjectURL` ทุกครั้งที่สลับไฟล์หรือ Unmount |
| **Validation Flow** | ตรวจสอบขนาดไฟล์ด้วย If-Else ใน Event Handler กระจัดกระจาย | ตรวจสอบผ่าน Single Zod Schema ด้วย `.refine()` ผูกกับ `zodResolver` |
| **User Experience (UX)** | ต้องคลิกปุ่ม Browse ไฟล์ ไม่รองรับ Drag & Drop และไม่มี Preview | รองรับการลากไฟล์วาง, แสดงความกว้าง/ขนาด, และมีปุ่มกดลบรูปทันที |
| **การส่งข้อมูลไป Backend** | เขียนแยกคำขอ อัปโหลดรูปขึ้น Cloud ก่อน แล้วค่อยส่ง Form JSON | ห่อรวมเป็น `FormData` เพียงครั้งเดียว ส่งทั้งข้อความและไฟล์ได้พร้อมกัน |

## 5. ผิด vs ถูก (Anti-patterns vs Best Practices)

### 5.1 ผิด ❌: ใส่ Header `Content-Type: multipart/form-data` ด้วยตนเองใน `fetch()`

```typescript
// ❌ ผิดร้ายแรง: การกำหนด Content-Type แบบนี้จะทำให้เซิร์ฟเวอร์ (เช่น NestJS / Multer) พัง!
await fetch('/api/upload', {
  method: 'POST',
  headers: {
    'Content-Type': 'multipart/form-data', // ❌ ห้ามเด็ดขาด!
  },
  body: formData,
});
```

```typescript
// ✅ ถูกต้อง: ละเว้น Content-Type ให้เบราว์เซอร์สร้าง Boundary String เองอัตโนมัติ
await fetch('/api/upload', {
  method: 'POST',
  // เบราว์เซอร์จะเติม: "multipart/form-data; boundary=----WebKitFormBoundaryXYZ..." ให้เอง
  body: formData,
});
```

### 5.2 ผิด ❌: ลืม Cleanup Object URL เมื่อ Component มีการ Unmount หรือเปลี่ยนรูป

```tsx
// ❌ ผิด: Memory Leak! ทุกครั้งที่เลือกไฟล์ใหม่ Memory จะจองพื้นที่เพิ่มขึ้นเรื่อยๆ
const handleFile = (file: File) => {
  const url = URL.createObjectURL(file);
  setPreview(url); // ไม่เคยสั่ง revokeObjectURL()
};
```

```tsx
// ✅ ถูกต้อง: คืนหน่วยความจำใน Cleanup Phase ของ useEffect
useEffect(() => {
  if (!file) return;
  const url = URL.createObjectURL(file);
  setPreview(url);
  return () => URL.revokeObjectURL(url); // ✅ คืน RAM ทันที
}, [file]);
```

## 6. ควรใช้เมื่อไหร่ / ไม่ควรใช้เมื่อไหร่

### ควรใช้แนวทางนี้เมื่อ:
- การอัปโหลดรูปโปรไฟล์ (Avatar), ตราสัญลักษณ์ (Logo), สลิปโอนเงิน (Payment Slip), หรือเอกสาร KYC
- ไฟล์มีขนาดมาตรฐาน (เช่น 1MB ถึง 20MB) ที่สามารถส่งผ่าน Form Submission ทั่วไปได้
- ต้องการแสดง Image Preview ทันทีในเบราว์เซอร์ของผู้ใช้

### ไม่ควรใช้แนวทางนี้เมื่อ:
- **ไฟล์ขนาดใหญ่มากๆ (Large Files > 100MB หรือระดับหลาย GB)**: เช่น ไฟล์วิดีโอ 4K หรือไฟล์ Backup ขนาดใหญ่ เพราะการส่งผ่าน Web Application Server จะกิน CPU/Memory สูงมาก (ควรใช้ **S3/GCS Presigned URLs** ทำ Direct Multipart Chunked Upload จากเบราว์เซอร์ตรงไปยัง Cloud Storage แทน)
- ฟอร์มที่ต้องการเพียงชื่อ URL ของรูปที่มีอยู่แล้วบน CDN

## 7. คำถามสัมภาษณ์งาน (Interview Questions)

### Q1: ทำไมการใช้ `URL.createObjectURL` เพื่อทำ Image Preview ใน React ถึงเสี่ยงต่อการเกิด Memory Leak และเรามีกลยุทธ์จัดการเรื่องนี้อย่างไร?
**แนวทางตอบแบบ Senior**:
"`URL.createObjectURL(file)` สร้าง Internal Mapping และตรึง Pointer ไปยังตำแหน่ง Memory ของไฟล์นั้นไว้ในระบบเบราว์เซอร์ เพื่อให้เราสามารถใช้ URL ชั่วคราว (เช่น `blob:http://...`) บนแท็ก `<img>` ได้ครับ

ความเสี่ยงคือ **Browser Garbage Collector จะไม่สามารถลบ Memory ก้อนนี้ทิ้งได้เอง** จนกว่าหน้านั้นจะถูกปิด หรือมีคำสั่งสั่งปลดปล่อย Memory อย่างชัดเจน หากผู้ใช้ทดลองเลือกไฟล์ภาพความละเอียดสูง 10 รูปสลับไปมา RAM จะถูกจองสะสมไปเรื่อยๆ จนอาจทำให้แท็บบนสมาร์ตโฟนหรือเครื่อง Client ค้าง (OOM Crash)

**กลยุทธ์การป้องกัน**:
เราต้องบริหารจัดการ Lifecycle ผ่าน **`useEffect` Cleanup Function** ครับ ทุกครั้งที่คอมโพเนนต์รับไฟล์ใหม่เข้ามา เราจะสร้าง URL ขึ้นมา และใน Return Callback ของ Effect เราจะเรียก **`URL.revokeObjectURL(currentUrl)`** เพื่อสั่งให้เบราว์เซอร์ปลดปล่อยทรัพยากรทันทีที่ผู้ใช้เปลี่ยนรูปใหม่หรือนำทางออกจากหน้าจอนั้นครับ"

### Q2: ในการส่ง `FormData` ผ่านฟังก์ชัน `fetch` เหตุใดเราจึง "ห้าม" ระบุ Header `'Content-Type': 'multipart/form-data'` ด้วยตนเอง?
**แนวทางตอบแบบ Senior**:
"นี่เป็นข้อผิดพลาดคลาสสิกที่พบบ่อยมากครับ ในโปรโตคอล HTTP เมื่อส่งข้อมูลแบบ `multipart/form-data` ตัวแพ็กเก็ตต้องการสิ่งที่เรียกว่า **'Boundary String'** (เช่น `boundary=----WebKitFormBoundary7MA4YWxkTrZu0gW`) เพื่อเป็นตัวคั่นแยกระหว่างฟิลด์ข้อความแต่ละตัวและ Binary Data ของแต่ละไฟล์

หากเราเขียน Header ทับด้วยตนเองเป็น `'Content-Type': 'multipart/form-data'` เบราว์เซอร์จะไม่สามารถต่อท้ายพารามิเตอร์ `boundary` เข้าไปใน Header ได้ ผลลัพธ์คือ **Web Server ฝั่ง Backend (เช่น Multer ใน Express/NestJS) จะไม่สามารถ Parse เนื้อหา Multipart ได้** เพราะไม่รู้ว่าจุดสิ้นสุดของแต่ละฟิลด์อยู่ตรงไหน และจะปฏิเสธคำขอด้วย Error ประเภท Malformed Request ครับ

**แนวทางที่ถูกต้อง**: เราเพียงแค่ส่ง `body: formData` โดยไม่ต้องระบุ `Content-Type` ใน Header เลย แล้วปล่อยให้เบราว์เซอร์สร้าง Header พร้อม Boundary เฉพาะตัวให้อัตโนมัติครับ"
