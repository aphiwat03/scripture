# AI Integration

การยกระดับระบบอีคอมเมิร์ซยุคใหม่ให้โดดเด่นกว่าคู่แข่งสามารถทำได้ด้วยการผสานความสามารถของ **Large Language Models (LLM)** เข้ากับข้อมูลธุรกิจจริง ในระบบ **Smart Butcher Marketplace** เราสามารถนำ **Groq SDK (`groq-sdk`)** ร่วมกับโมเดลความเร็วสูงอย่าง **Llama 3.1 8B (`llama-3.1-8b-instant`)** มาสร้างฟีเจอร์ *AI Sommelier & Master Butcher* ที่ช่วยแนะนำระดับความสุก อุณหภูมิการย่าง และซอสที่เข้ากับเนื้อวากิวแต่ละชิ้น (`Product`) หรือช่วยสรุปคำแนะนำการจัดเตรียมออเดอร์ (`Order`) โดยทั้งหมดต้องถูกเรียกใช้งานผ่านฝั่ง **NestJS 11 Backend** อย่างปลอดภัย มีการควบคุมต้นทุน Token, กำหนด Timeout, บังคับผลลัพธ์เป็น Structured JSON และป้องกันช่องโหว่ Prompt Injection อย่างรัดกุม

<Callout type="warning" title="ข้อควรตรวจสอบกับเอกสารทางการของ Groq">
ชื่อโมเดล (เช่น `llama-3.1-8b-instant`) รวมถึงพารามิเตอร์และ API ของ Groq อาจมีการอัปเดตเปลี่ยนแปลงหรือปลดระวาง (Deprecation) ตามรอบของผู้ให้บริการ แนะนำให้ตรวจสอบรายการโมเดลที่รองรับล่าสุดและขีดจำกัดการใช้งานที่เอกสารทางการของ Groq (`https://console.groq.com/docs/models`) เสมอก่อนนำไปตั้งค่าบนระบบ Production
</Callout>
