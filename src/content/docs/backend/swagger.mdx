# Swagger

ในการพัฒนาระบบที่แยกส่วนระหว่าง Frontend (Next.js) และ Backend (NestJS 11) ออกจากกันอย่างในระบบ **Smart Butcher Marketplace** ปัญหาคอขวดที่ทำให้ทีมพัฒนาเสียเวลามากที่สุดคือการสื่อสารเรื่องโครงสร้าง API (เช่น ชื่อฟิลด์สะกดไม่ตรงกัน, ชนิดข้อมูลเป็น `string` หรือ `number`, หรือไม่รู้ว่า Endpoint นี้คืนค่า HTTP Status ใดบ้าง) การใช้แพ็กเกจ **`@nestjs/swagger`** ตามมาตรฐาน **OpenAPI 3.0** ช่วยให้เราสร้างเอกสาร API แบบโต้ตอบได้ (Interactive Swagger UI) และสร้างไฟล์สัญญา (API Contract) จากคลาส DTO และ Controller ในโค้ดโดยตรง ทำให้เอกสารตรงกับโค้ดจริงเสมอ (Single Source of Truth)

| หัวข้อในหน้านี้ | รายละเอียดหลัก |
| :--- | :--- |
| [1. การติดตั้งและตั้งค่า SwaggerModule (OpenAPI) ใน NestJS 11](/docs/backend/swagger/swagger-module) | การกำหนดค่า `DocumentBuilder`, `SwaggerModule.createDocument()` และการปิด Swagger ใน Production |
| [2. การใช้ Decorators หลัก (@ApiTags, @ApiOperation, @ApiProperty, @ApiResponse)](/docs/backend/swagger/api-decorators) | การอธิบายโครงสร้าง Request/Response DTO, Enum และ Multipart File Upload |
| [3. การเปิดใช้งาน NestJS Swagger CLI Plugin เพื่อลดโค้ดซ้ำซ้อน](/docs/backend/swagger/cli-plugin) | การใช้ AST Transformer ใน `nest-cli.json` เพื่ออ่าน Type และ JSDoc อัตโนมัติตอนคอมไพล์ |
| [4. การกำหนด Security Schemes สำหรับ JWT Bearer และ HttpOnly Cookie](/docs/backend/swagger/security-schemes) | การตั้งค่า `addBearerAuth()` และ `addCookieAuth()` เพื่อทดสอบ Protected Endpoints บน Swagger UI |
| [5. การทำงานร่วมกับทีม Frontend และการ Generate TypeScript Client อัตโนมัติ](/docs/backend/swagger/codegen-client) | การ Export `openapi.json` และการใช้ `openapi-typescript` สร้าง Type-safe Client ให้ Next.js |
| [ข้อผิดพลาดที่พบบ่อย (Anti-patterns)](/docs/backend/swagger/pitfalls) | ข้อควรระวังในการเขียนเอกสาร OpenAPI ในโปรเจกต์ NestJS |
| [Checklist สรุป](/docs/backend/swagger/pitfalls) | รายการตรวจสอบความสมบูรณ์ของเอกสาร API ก่อนส่งมอบให้ทีม Frontend |
| [ลำดับการเรียนที่แนะนำ และ ดูเพิ่มเติมที่](/docs/backend/swagger/pitfalls) | เส้นทางการศึกษาต่อยอดด้าน REST API, Authentication และ AI Integration |
