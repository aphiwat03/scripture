# Node.js

(สำหรับพื้นฐาน TypeScript และ JavaScript สามารถดูเพิ่มเติมได้ที่กลุ่ม Frontend ในหัวข้อ [TypeScript](/docs/typescript) และ [React 19](/docs/react) โดยไม่ต้องอธิบายซ้ำในเอกสารนี้)

<Callout type="note" title="Node.js ในสถาปัตยกรรม Backend ยุคใหม่">
Node.js เป็น JavaScript Runtime ที่ทำงานบน V8 Engine และ libuv ออกแบบมาสำหรับสร้างระบบเครือข่ายที่รองรับการทำงานแบบ I/O-intensive และ Concurrency สูง เอกสารฉบับนี้เจาะลึกกลไกภายในที่นักพัฒนาระดับ Senior Backend จำเป็นต้องเชี่ยวชาญ โดยใช้ระบบ **Smart Butcher Marketplace** (แพลตฟอร์มตลาดสดเนื้อพรีเมียมออนไลน์) เป็นตัวอย่างเชิงปฏิบัติการตลอดทั้งเอกสาร
</Callout>
