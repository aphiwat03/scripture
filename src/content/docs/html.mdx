## ภาพรวม HTML5 & Modern Web Foundation

**HTML (HyperText Markup Language)** คือรากฐานและกระดูกสันหลังของเว็บแอปพลิเคชันทุกชิ้นในโลก แม้ในยุคที่เทคโนโลยี Frontend จะพัฒนาไปไกลด้วย React 19, Next.js 16, TypeScript และ Tailwind CSS แต่สิ่งที่ถูกส่งมอบไปยังเบราว์เซอร์ของผู้ใช้ปลายทาง และสิ่งที่ Google Crawler ตรวจสอบ ก็คือ **HTML DOM** เสมอ

ตามมาตรฐาน **HTML Living Standard (โดย WHATWG)** ในปัจจุบัน HTML5 ไม่ใช่แค่เรื่องของการวางข้อความ แต่เป็นระบบนิเวศน์ที่ครอบคลุมถึง:
- **Semantic Structure**: การให้ความหมายที่ถูกต้องแก่องค์ประกอบของหน้า
- **Accessibility Tree**: สะพานเชื่อมระหว่างโค้ดและ Screen Readers สำหรับผู้พิการ
- **Browser Parsing Engine**: การแปลง Text เป็น DOM Tree และ Layout Tree
- **Core Security & Performance**: การควบคุมลำดับการดาวน์โหลด Resource และป้องกันช่องโหว่ XSS
