## 1. แนวคิด (Concept)

ในการพัฒนาระบบ **Enterprise Analytics Dashboard** ระดับโปรดักชันสำหรับธุรกิจ E-Commerce หรือ SaaS หัวใจสำคัญไม่ได้อยู่ที่การใส่ชาร์ตให้มากที่สุดเท่าที่จะทำได้ แต่คือการจัดวางข้อมูลตามลำดับการรับรู้ของมนุษย์ (**Visual Hierarchy & Information Architecture**):

1. **Top-Level KPI Overview**: แสดงตัวเลขชี้วัดผลงานหลัก (StatCards) เช่น รายได้รวม, กำไรสุทธิ, คำสั่งซื้อใหม่ และอัตราการเติบโต เพื่อให้ผู้บริหารมองเห็นภาพรวมใน 3 วินาทีแรก
2. **Macro Trends (ภาพรวมแนวโน้มตามเวลา)**: ใช้ **ComposedChart (Bar + Line)** แสดงปริมาณยอดขาย (Volume) ควบคู่กับอัตรากำไร (Profit Margin %) บนแกน Y คู่ (Dual Y-Axis)
3. **Micro Segmentation (การแบ่งกลุ่มข้อมูล)**: ใช้ **Donut Chart** แสดงสัดส่วนรายได้แยกตามหมวดหมู่สินค้า
4. **Operational Pipeline (สถานะการดำเนินงาน)**: ใช้ **BarChart** แสดงจำนวนคำสั่งซื้อในแต่ละขั้นตอนของกระบวนการ Fulfillment
5. **Fluid Responsive Grid**: ออกแบบ Grid System ด้วย Tailwind CSS ที่ขยายตัวได้ยืดหยุ่นตั้งแต่จอสมาร์ตโฟนไปจนถึงจออัลตร้าไวด์

## 2. หลักการเบื้องหลัง (Under the Hood)

### สถาปัตยกรรม Dual Y-Axis ใน `ComposedChart`

ความท้าทายของกราฟแบบหลายมิติคือ การรวมหน่วยวัดที่ต่างกันคนละขั้ว (เช่น หน่วย "บาท" หลักล้าน กับหน่วย "เปอร์เซ็นต์" 0-100%) ไว้ในกราฟเดียวกัน:

```
[ ComposedChart Data Point ]
  { month: 'ม.ค.', revenue: 2500000, margin: 28.5 }
             │
             ├──► yAxisId="left"  (Currency Scale: 0 -> 3M THB) ──► <Bar dataKey="revenue" />
             │
             └──► yAxisId="right" (Percentage Scale: 0 -> 100%)  ──► <Line dataKey="margin" />
```

* **Domain Alignment**: แกนซ้ายและขวาต้องกำหนด `domain` หรือการคำนวณ Tick ให้เหมาะสม เพื่อไม่ให้เส้น Line ทับซ้อนกับยอดแท่ง Bar จนผู้ใช้อ่านลำบาก
* **Independent Tooltip Formatting**: Tooltip กลางจะต้องตรวจสอบ `entry.dataKey` เพื่อเลือกแสดงสกุลเงิน `฿` สำหรับยอดขาย และเติม `%` สำหรับกำไร

## 3. ตัวอย่างโค้ด (TypeScript / TSX)

### ตัวอย่างที่ 1: Dual-Axis ComposedChart (ยอดขายและอัตรากำไรสุทธิ)

คอมโพเนนต์นี้แสดงการรวม `<Bar>` และ `<Line>` เข้าด้วยกัน พร้อมแกน Y ซ้าย-ขวา และ Custom Tooltip ที่แสดงข้อมูลสองหน่วยวัดอย่างถูกต้อง

```tsx filename="src/components/dashboard/revenue-margin-composed-chart.tsx"
'use client';

import * as React from 'react';
import {
  Bar,
  CartesianGrid,
  ComposedChart,
  Legend,
  Line,
  ResponsiveContainer,
  Tooltip,
  XAxis,
  YAxis,
} from 'recharts';

export interface MonthlyFinancial {
  month: string;
  revenue: number; // บาท
  profitMargin: number; // เปอร์เซ็นต์ (0 - 100)
}

const mockFinancials: MonthlyFinancial[] = [
  { month: 'ม.ค.', revenue: 1450000, profitMargin: 24.2 },
  { month: 'ก.พ.', revenue: 1820000, profitMargin: 26.8 },
  { month: 'มี.ค.', revenue: 2150000, profitMargin: 31.0 },
  { month: 'เม.ย.', revenue: 1980000, profitMargin: 28.4 },
  { month: 'พ.ค.', revenue: 2400000, profitMargin: 33.5 },
  { month: 'มิ.ย.', revenue: 2850000, profitMargin: 35.2 },
  { month: 'ก.ค.', revenue: 3100000, profitMargin: 34.0 },
];

export function RevenueMarginComposedChart() {
  return (
    <div className="w-full rounded-2xl border border-border bg-card p-6 shadow-sm">
      <div className="mb-6 flex flex-col justify-between gap-2 sm:flex-row sm:items-center">
        <div>
          <h3 className="text-lg font-bold text-card-foreground">
            แนวโน้มยอดขายและอัตรากำไร (Revenue vs Profit Margin)
          </h3>
          <p className="text-sm text-muted-foreground">
            วิเคราะห์ความสัมพันธ์ระหว่างการเติบโตของรายได้กับประสิทธิภาพการทำกำไร
          </p>
        </div>
      </div>

      <div className="h-[360px] w-full min-w-0">
        <ResponsiveContainer width="100%" height="100%">
          <ComposedChart
            data={mockFinancials}
            margin={{ top: 20, right: 20, left: 0, bottom: 0 }}
          >
            <CartesianGrid strokeDasharray="3 3" vertical={false} className="stroke-border/60" />
            
            <XAxis
              dataKey="month"
              tickLine={false}
              axisLine={false}
              tick={{ fontSize: 12, fill: 'hsl(var(--muted-foreground))' }}
            />
            
            {/* แกนซ้าย: ยอดขาย (THB) */}
            <YAxis
              yAxisId="left"
              orientation="left"
              tickLine={false}
              axisLine={false}
              tickFormatter={(v: number) => `฿${(v / 1000000).toFixed(1)}M`}
              tick={{ fontSize: 12, fill: 'hsl(var(--muted-foreground))' }}
            />
            
            {/* แกนขวา: อัตรากำไร (%) */}
            <YAxis
              yAxisId="right"
              orientation="right"
              tickLine={false}
              axisLine={false}
              domain={[0, 50]}
              tickFormatter={(v: number) => `${v}%`}
              tick={{ fontSize: 12, fill: 'hsl(var(--muted-foreground))' }}
            />

            <Tooltip
              content={({ active, payload, label }) => {
                if (!active || !payload?.length) return null;
                return (
                  <div className="rounded-xl border border-border bg-popover p-3 text-xs shadow-lg">
                    <p className="mb-2 font-bold text-popover-foreground">{label}</p>
                    {payload.map((entry) => {
                      const isMargin = entry.dataKey === 'profitMargin';
                      const value = entry.value as number;
                      return (
                        <div key={entry.dataKey} className="flex items-center justify-between gap-4 py-0.5">
                          <span className="flex items-center gap-1.5 text-muted-foreground">
                            <span
                              className="h-2 w-2 rounded-full"
                              style={{ backgroundColor: entry.color }}
                            />
                            {isMargin ? 'อัตรากำไร' : 'ยอดขายรวม'}:
                          </span>
                          <span className="font-semibold text-foreground">
                            {isMargin ? `${value.toFixed(1)}%` : `฿${value.toLocaleString()}`}
                          </span>
                        </div>
                      );
                    })}
                  </div>
                );
              }}
            />

            <Legend
              verticalAlign="top"
              align="right"
              wrapperStyle={{ paddingBottom: '16px' }}
            />

            <Bar
              yAxisId="left"
              dataKey="revenue"
              name="ยอดขาย (THB)"
              fill="hsl(var(--primary, 220 70% 50%))"
              radius={[6, 6, 0, 0]}
              maxBarSize={44}
            />

            <Line
              yAxisId="right"
              type="monotone"
              dataKey="profitMargin"
              name="อัตรากำไร (%)"
              stroke="#10b981"
              strokeWidth={3}
              dot={{ r: 4, fill: '#10b981' }}
              activeDot={{ r: 6, stroke: '#ffffff', strokeWidth: 2 }}
            />
          </ComposedChart>
        </ResponsiveContainer>
      </div>
    </div>
  );
}
```

## 4. เทียบกับวิธีอื่น (Recharts Dashboard vs BI Tools Embedded vs Canvas Engine)

| มิติการเปรียบเทียบ | Custom Recharts Dashboard | Embedded BI (Metabase / Power BI) | Canvas-based (Chart.js / ECharts) |
| :--- | :--- | :--- | :--- |
| **สิทธิ์ความเป็นเจ้าของ UI / UX** | **100% สมบูรณ์** ปรับ Styling, Micro-interactions และ Design Token ตามใจชอบ | ถูกจำกัดด้วยกรอบ iFrame, ปรับธีมให้เข้ากับเว็บหลักได้ยาก | ปานกลาง ต้องวาด Tooltip หรือ Custom Widget เองใน Canvas |
| **การผูก Action ภายในระบบ** | **ไร้รอยต่อ** คลิกที่แท่งกราฟเพื่อเปิด Slide-over Drawer หรือ Dialog แก้ไขออร์เดอร์ได้ทันที | ทำได้ยาก การสื่อสารผ่าน `postMessage` มีข้อจำกัด | ทำได้ปานกลาง ต้องแปลงพิกัด Mouse Click เป็น Index |
| **ต้นทุนลิขสิทธิ์ (Licensing Cost)** | **ฟรีและ Open-source** ไม่มีค่าใช้จ่ายรายเดือน | มีค่า License ต่อจำนวนผู้ใช้ (Per-seat pricing) ซึ่งสูงมาก | ฟรีและ Open-source |
| **ประสิทธิภาพการเรนเดอร์** | เหมาะสำหรับ Dashboard ทั่วไป (1 - 20 กราฟต่อหน้า) | สูง แต่โหลด iFrame หนักในช่วงแรก | เหมาะที่สุดสำหรับระบบแสดงข้อมูลดิบหลายหมื่นจุด |

## 5. ผิด vs ถูก (Anti-patterns vs Best Practices)

### ข้อผิดพลาดที่ 1: กำหนดสเกลแกน Y คู่โดยไม่ตั้ง `domain` จนเส้นกราฟถูกแท่งบัง

```tsx
// ❌ ผิด: ปล่อยให้ Recharts คำนวณขอบเขตแกนขวาแบบอัตโนมัติ 
// หากกำไรอยู่ระหว่าง 20-30% เส้นจะวิ่งอยู่ตรงกึ่งกลางตัดกับยอดแท่งยอดขายจนดูไม่รู้เรื่อง
<YAxis yAxisId="right" orientation="right" />

// ✅ ถูกต้อง: กำหนด domain ให้ชัดเจน เช่น [0, 50] หรือ [0, 100] เพื่อให้เส้นลอยอยู่เหนือแท่งอย่างสมดุล
<YAxis yAxisId="right" orientation="right" domain={[0, 50]} unit="%" />
```

### ข้อผิดพลาดที่ 2: สร้างไฟล์ Dashboard ขนาดมหึมาไฟล์เดียว (Monolithic File)

```tsx
// ❌ ผิด: เขียน StatCards, ComposedChart, Donut, ตาราง รวมกันใน page.tsx ยาว 2,000 บรรทัด
// ทำให้ Re-render ลามทั้งหน้าเมื่อมี State เปลี่ยนเพียงจุดเดียว

// ✅ ถูกต้อง: แยกแต่ละ Chart Widget ออกเป็นคอมโพเนนต์ย่อย และห่อหุ้มด้วย Error Boundary แยกอิสระ
<DashboardGrid>
  <ErrorBoundary fallback={<ChartErrorFallback />}>
    <RevenueMarginComposedChart />
  </ErrorBoundary>
  <ErrorBoundary fallback={<ChartErrorFallback />}>
    <CategoryShareDonut />
  </ErrorBoundary>
</DashboardGrid>
```

### ข้อผิดพลาดที่ 3: ไม่ใส่ `unit` หรือ Label อธิบายแกน Y

```tsx
// ❌ ผิด: แกนแสดงแค่ตัวเลข 1, 2, 3 ผู้ใช้ไม่รู้ว่าเป็นล้านบาท, พันบาท, หรือจำนวนชิ้น
<YAxis />

// ✅ ถูกต้อง: ใส่ tickFormatter หรือระบุหน่วยอย่างชัดเจนเสมอ
<YAxis tickFormatter={(v) => `฿${(v / 1e6).toFixed(1)}M`} />
```

## 6. ควรใช้เมื่อไหร่ / ไม่ควรใช้เมื่อไหร่

### ควรใช้ Recharts สร้าง Enterprise Dashboard เมื่อ:
- เว็บไซต์มี Design System เฉพาะตัว (Tailwind / shadcn/ui) และต้องการให้ Dashboard ดูเป็นเนื้อเดียวกับระบบ
- มีความต้องการทำ Custom Drill-down เช่น เมื่อคลิกแท่งกราฟเดือน "มี.ค." แล้วให้ฟิลเตอร์ข้อมูลในตารางข้างล่างตามทันที
- ผู้ใช้เข้าใช้งานผ่านหลากหลายอุปกรณ์ (Desktop, iPad, iPhone)

### ไม่ควรใช้เมื่อ:
- Dashboard เป็นแบบ Real-time High-frequency Monitoring สำหรับห้องควบคุม Network Operations Center (NOC) ที่มี Data Point อัปเดตทุก 50 มิลลิวินาที

## 7. คำถามสัมภาษณ์งาน (Interview Questions)

### Q1: ในการทำ Dual-Axis Chart (แกน Y ด้านซ้ายเป็นยอดเงินบาท แกน Y ด้านขวาเป็นร้อยละกำไร) คุณมีหลักการทางคณิตศาสตร์และการออกแบบอย่างไรเพื่อป้องกันไม่ให้เส้นกราฟกับแท่งกราฟบดบังกันจนสูญเสียความสามารถในการอ่าน?
**แนวทางตอบแบบ Senior Developer**:
1. **การกำหนด Domain ที่มี headroom**: สำหรับแกนขวาที่เป็นอัตราส่วน (%) แทนที่จะปล่อยให้เริ่มจากค่าต่ำสุดถึงสูงสุดจริง เช่น `[24, 35]` ซึ่งจะทำให้เส้นขยายเต็มความสูงและตัดผ่านแท่งยอดขาย เราควรกำหนด Domain ให้กว้างขึ้น เช่น `[0, 50]` หรือ `[0, 100]` เพื่อยกเส้นแนวโน้มให้ลอยเด่นอยู่ในระดับสายตาด้านบน
2. **การจัดระดับความโปร่งใสและสี (Visual Weight)**: กำหนดสีแท่ง Bar ด้วยค่าความทึบแสง (Opacity) เช่น `0.85` หรือใช้โทนสีที่นุ่มนวลกว่า ขณะที่เส้น Line ใช้น้ำหนักเส้นหนา (`strokeWidth={3}`) และเลือกสีที่มีค่า Contrast สูงตัดกับแท่ง
3. **การออกแบบ Tooltip รวมศูนย์ (Unified Crosshair Tooltip)**: ออกแบบ Tooltip เพียงตัวเดียวที่แสดงทั้งยอดเงินและเปอร์เซ็นต์พร้อมกันเมื่อเลื่อนเมาส์ผ่านจุด X เดียวกัน พร้อมระบุสีสัญลักษณ์ให้ตรงกับชุดข้อมูล

### Q2: เมื่อหน้าแดชบอร์ดมีชาร์ตมากกว่า 6 ชิ้น และมีตัวเลือก Filter ช่วงเวลา (เช่น วันนี้, 7 วัน, 30 วัน, ไตรมาส) คุณจะวางสถาปัตยกรรม State และ Network Fetching อย่างไรไม่ให้หน้าเว็บกระตุก?
**แนวทางตอบแบบ Senior Developer**:
1. **URL-driven State Management**: เก็บค่า Filter ลงใน URL Search Params (เช่น `?range=30d`) เพื่อให้รองรับการแชร์ลิงก์และกดปุ่ม Back/Forward ของเบราว์เซอร์
2. **Parallel Data Fetching ผ่าน React Server Components หรือ TanStack Query**:
   - ใช้ RSC ดึงข้อมูลคู่ขนานด้วย `Promise.all()` หรือแตกเป็นแต่ละ Suspense Boundary เพื่อให้แต่ละชาร์ตสตรีมข้อมูลแยกกัน (Streaming SSR) ชาร์ตไหนเสร็จก่อนก็แสดงผลก่อน
   - หากทำบน Client ให้ใช้ TanStack Query เพื่อแชร์แคชข้อมูลและทำ Background Refetch อย่างนุ่มนวล
3. **ป้องกัน Cascade Re-render**: ห่อหุ้ม Chart Component แต่ละตัวด้วย `React.memo` และส่งเฉพาะ Data Array ย่อยที่ผ่านการ Transform แล้วเข้าไปเป็น Props เพื่อป้องกันไม่ให้กราฟที่ไม่ได้เปลี่ยนข้อมูลต้องวาด SVG ใหม่อีกรอบ
