# Built-in Functions & Methods: รวมฟังก์ชันมาตรฐานที่ใช้บ่อยที่สุดในงานจริง

ในการพัฒนาเว็บแอปพลิเคชันระดับ Production ด้วย **TypeScript & JavaScript** มากกว่า 80% ของ Logic การแปลงข้อมูล (Data Transformation) ล้วนพึ่งพา **Built-in Methods & Functions** ที่ติดมากับภาษา การเข้าใจพฤติกรรมเชิงลึกว่าฟังก์ชันใดแก้ไขข้อมูลเดิม (Mutating) หรือสร้างข้อมูลใหม่ (Non-mutating), ฟังก์ชันใดมีความซับซ้อนเชิงเวลา $O(1)$ หรือ $O(n)$, และการเลือกใช้งานอย่างถูกต้อง จึงเป็นทักษะชี้ขาดความสะอาดและประสิทธิภาพของโค้ด

## 1. หมวด Array Methods (ตระกูลจัดการอาเรย์)

อาเรย์คือโครงสร้างข้อมูลที่ใช้งานบ่อยที่สุดใน Frontend และ Backend สำหรับการเขียนโค้ดสไตล์ Functional และ React ควรยึดหลัก **Immutability (ไม่แก้ไขข้อมูลต้นฉบับ)** เสมอ

### 1.1 `map()`: แปลงร่างข้อมูลทุกตัวในอาเรย์
- **คุณสมบัติ:** **Non-mutating** (คืนอาเรย์ใหม่ที่มีจำนวนสมาชิกเท่าเดิมเป๊ะ)
- **การใช้งานหลัก:** ดึงเฉพาะฟิลด์ที่ต้องการ, แปลงหน่วย, ห่อหุ้ม JSX Component ใน React

```typescript filename="array-map.ts"
interface MeatItem {
  sku: string;
  name: string;
  pricePerKg: number;
}

const meatInventory: MeatItem[] = [
  { sku: "WAG-01", name: "Miyazaki Wagyu A5", pricePerKg: 3800 },
  { sku: "ANG-02", name: "Black Angus Ribeye", pricePerKg: 1450 },
];

// แปลงให้เป็นป้ายราคาติดหน้าร้าน
const displayLabels: string[] = meatInventory.map(
  (item) => `${item.name} - ฿${item.pricePerKg.toLocaleString()}/kg`
);
// ผลลัพธ์: ["Miyazaki Wagyu A5 - ฿3,800/kg", "Black Angus Ribeye - ฿1,450/kg"]
```

---

### 1.2 `filter()`: กรองข้อมูลที่ต้องการ
- **คุณสมบัติ:** **Non-mutating** (คืนอาเรย์ใหม่ที่มีจำนวนสมาชิก $\le$ เดิม เฉพาะตัวที่ Callback ส่งค่า `true`)
- **การใช้งานหลัก:** ค้นหา, กรองสถานะ, คัดแยกไอเทมที่ถูกลบ

```typescript filename="array-filter.ts"
interface Order {
  id: string;
  total: number;
  status: "PENDING" | "PAID" | "CANCELLED";
}

const orders: Order[] = [
  { id: "ORD-1", total: 4500, status: "PAID" },
  { id: "ORD-2", total: 1200, status: "PENDING" },
  { id: "ORD-3", total: 890, status: "CANCELLED" },
];

// กรองเฉพาะออเดอร์ที่จ่ายเงินแล้ว
const paidOrders = orders.filter((order) => order.status === "PAID");
```

---

### 1.3 `reduce()`: รวมทั้งก้อนเป็นผลลัพธ์เดียว
- **คุณสมบัติ:** **Non-mutating** (ทรงพลังที่สุดในอาเรย์ สามารถแปลงอาเรย์เป็นตัวเลข, สตริง, อ็อบเจกต์ หรือแม้กระทั่งอาเรย์ใหม่)
- **ไวยากรณ์:** `array.reduce((accumulator, currentItem, index) => { ... }, initialValue)`
- **การใช้งานหลัก:** คำนวณยอดเงินรวม, Group By หมวดหมู่, นับความถี่ข้อมูล

```typescript filename="array-reduce.ts"
// 1. คำนวณยอดเงินรวมของตะกร้า
const cartItems = [
  { cut: "Striploin", price: 1500, quantity: 2 },
  { cut: "Tenderloin", price: 1800, quantity: 1 },
];

const grandTotal = cartItems.reduce(
  (acc, item) => acc + item.price * item.quantity,
  0 // <--- ห้ามลืมกำหนด Initial Value เสมอ!
);
// grandTotal = 4800

// 2. จัดกลุ่มข้อมูล (Group By Category)
interface Product {
  name: string;
  category: "BEEF" | "PORK" | "SAUCE";
}

const products: Product[] = [
  { name: "Wagyu A5", category: "BEEF" },
  { name: "Kurobuta Pork", category: "PORK" },
  { name: "Truffle Butter", category: "SAUCE" },
  { name: "Angus Ribeye", category: "BEEF" },
];

const grouped = products.reduce((acc, product) => {
  const cat = product.category;
  if (!acc[cat]) {
    acc[cat] = [];
  }
  acc[cat].push(product.name);
  return acc;
}, {} as Record<string, string[]>);

/* ผลลัพธ์:
{
  BEEF: ["Wagyu A5", "Angus Ribeye"],
  PORK: ["Kurobuta Pork"],
  SAUCE: ["Truffle Butter"]
}
*/
```

### 1.4 `find()` และ `findIndex()`: ค้นหาตัวแรกที่ตรงเงื่อนไข
- `find()`: คืนค่า **Object สมาชิกตัวแรกที่ตรงเงื่อนไข** หากไม่พบจะคืนค่า `undefined`
- `findIndex()`: คืนค่า **ดัชนี (Index) ตำแหน่งแรกที่พบ** หากไม่พบจะคืนค่า `-1`

```typescript filename="array-find.ts"
const meatCuts = [
  { id: "c1", name: "Pork Chop", stock: 12 },
  { id: "c2", name: "Wagyu Ribeye", stock: 0 },
  { id: "c3", name: "Angus Sirloin", stock: 5 },
];

// หาเนื้อที่ของหมด
const outOfStockCut = meatCuts.find((c) => c.stock === 0);
// outOfStockCut = { id: "c2", name: "Wagyu Ribeye", stock: 0 }

const outOfStockIndex = meatCuts.findIndex((c) => c.stock === 0);
// outOfStockIndex = 1
```

### 1.5 `some()` และ `every()`: ตรวจสอบเงื่อนไขแบบ Boolean
- `some()`: คืนค่า `true` หากมีสมาชิก **อย่างน้อย 1 ตัว** ตรงตามเงื่อนไข (หยุดตรวจทันทีเมื่อพบตัวแรก - Short-circuit)
- `every()`: คืนค่า `true` ก็ต่อเมื่อ **ทุกตัวในอาเรย์** ต้องตรงตามเงื่อนไข

```typescript filename="array-some-every.ts"
const orderItems = [
  { name: "Wagyu", isFrozen: true, weightKg: 1.2 },
  { name: "Dry-Aged Tomahawk", isFrozen: false, weightKg: 2.5 },
];

// ตรวจว่ามีสินค้าที่ต้องใช้รถห้องเย็นจัดส่งหรือไม่
const needsColdChain = orderItems.some((item) => item.isFrozen); // true

// ตรวจสอบว่าสินค้าทุกชิ้นมีน้ำหนักเกินเกณฑ์ขั้นต่ำ 1kg หรือไม่
const allOverWeight = orderItems.every((item) => item.weightKg >= 1.0); // true
```

### 1.6 `flatMap()`: แมปพร้อมคลี่อาเรย์ซ้อน (Unnesting)
- **คุณสมบัติ:** รวมการทำ `.map()` และ `.flat(1)` ไว้ในรอบเดียว ประสิทธิภาพดีกว่าการเรียกแยก
- **การใช้งานหลัก:** แตกข้อมูลแบบ One-to-Many เช่น ดึงรายการสินค้าทั้งหมดออกมาจากทุกคำสั่งซื้อ

```typescript filename="array-flatmap.ts"
interface CustomerOrder {
  orderId: string;
  items: string[];
}

const customerOrders: CustomerOrder[] = [
  { orderId: "ORD-1", items: ["Ribeye", "Tenderloin"] },
  { orderId: "ORD-2", items: ["Brisket"] },
  { orderId: "ORD-3", items: ["Wagyu A5", "Butter"] },
];

// ดึงรายการเนื้อทั้งหมดออกมาเป็นอาเรย์ชั้นเดียว
const allBoughtItems = customerOrders.flatMap((order) => order.items);
// ผลลัพธ์: ["Ribeye", "Tenderloin", "Brisket", "Wagyu A5", "Butter"]
```

### 1.7 `sort()` vs `toSorted()`: การเรียงลำดับข้อมูล
> [!CAUTION]
> `sort()` ของ JavaScript แบบดั้งเดิมจะ **แก้ไขข้อมูลในอาเรย์ต้นฉบับ (Mutate in-place)** และเรียงตามรหัสตัวอักษร Unicode ทำให้ตัวเลข `[10, 2, 5]` กลายเป็น `[10, 2, 5]` เพราะ `'10'` มาก่อน `'2'`!  
> ต้องใส่ Comparison Function `(a, b) => a - b` เสมอ  
> ในโมเดิร์น JavaScript/TypeScript (ES2023+) แนะนำให้ใช้ **`toSorted()`** เพราะ **Non-mutating**

```typescript filename="array-sort.ts"
const prices = [1200, 450, 3800, 890];

// ❌ แบบดั้งเดิม (Mutate ต้นฉบับ)
// prices.sort((a, b) => a - b);

// ✅ ปลอดภัยแบบ Immutable (ES2023)
const sortedPricesAscending = prices.toSorted((a, b) => a - b);
// [450, 890, 1200, 3800]

const sortedPricesDescending = prices.toSorted((a, b) => b - a);
// [3800, 1200, 890, 450]
```

### 1.8 `slice()` vs `splice()`: ตัดแบบปลอดภัย vs ตัดแก้ของเดิม
- **`slice(start, end)`**: **Non-mutating** คัดลอกส่วนหนึ่งของอาเรย์ออกมาเป็นอาเรย์ใหม่ ไม่กระทบของเดิม (ใช้ทำ Pagination)
- **`splice(start, deleteCount, ...items)`**: **Mutating** ควัก/ลบ/แทรกสมาชิกในอาเรย์เดิมโดยตรง

```typescript filename="array-slice-splice.ts"
const meatList = ["Ribeye", "Sirloin", "T-Bone", "Tenderloin", "Chuck"];

// การทำ Pagination ดึงหน้าที่ 1 ขนาด 2 ชิ้น (ไม่กระทบ meatList เดิม)
const pageOne = meatList.slice(0, 2); // ["Ribeye", "Sirloin"]
const pageTwo = meatList.slice(2, 4); // ["T-Bone", "Tenderloin"]
```

### 1.9 `includes()` และ `indexOf()`: เช็คการมีอยู่ของค่า
- `includes(value)`: คืนค่า `true` / `false` เหมาะกับการตรวจ Primitive values
- `indexOf(value)`: คืนค่าตำแหน่ง index หรือ `-1` เมื่อไม่พบ

```typescript filename="array-includes.ts"
const allowedGrades = ["A5", "A4", "PRIME"];
const customerGrade = "A5";

if (allowedGrades.includes(customerGrade)) {
  console.log("เกรดเนื้อพรีเมียมตรงตามเงื่อนไขส่งออก");
}
```

### 2.1 `split()`: หั่นข้อความออกเป็นอาเรย์
- **การใช้งานหลัก:** แปลง CSV เป็นอาเรย์, แยก Path, หั่นคำด้วย Space

```typescript filename="string-split.ts"
// 1. แยก Tags สินค้าจากสตริงที่คั่นด้วยลูกน้ำ
const tagString = "wagyu,dry-aged,halal,a5";
const tagList = tagString.split(","); 
// ["wagyu", "dry-aged", "halal", "a5"]

// 2. ดึง Username ออกจาก Email
const email = "somchai.butcher@smartbutcher.com";
const [username, domain] = email.split("@");
// username = "somchai.butcher", domain = "smartbutcher.com"
```

### 2.2 `join()`: ประกอบอาเรย์ข้อความกลับเป็นสตริง
- **การใช้งานหลัก:** สร้าง Breadcrumbs, สร้างสตริงสำหรับใส่ใน SQL Query, รวม ClassNames

```typescript filename="string-join.ts"
const categories = ["Home", "Meat", "Beef", "Wagyu A5"];
const breadcrumb = categories.join(" > ");
// "Home > Meat > Beef > Wagyu A5"

const selectedSkus = ["SKU-1", "SKU-2", "SKU-3"];
const urlQuery = selectedSkus.join("&sku=");
```

### 2.3 `replace()` และ `replaceAll()`: แทนที่ข้อความและ Regex
- `replace(target, replacement)`: แทนที่ **จุดแรกที่พบ** จุดเดียว
- `replaceAll(target, replacement)`: แทนที่ **ทุกจุดทั่วทั้งสตริง** (หรือใช้ `replace(/pattern/g, ...)` ด้วย Regex flag `g`)

```typescript filename="string-replace.ts"
// 1. ล้างขีดและเว้นวรรคออกจากเบอร์โทรศัพท์
const rawPhone = "081-234 5678";
const cleanPhone = rawPhone.replaceAll(/[- ]/g, ""); // "0812345678"
```

### 3.1 `Object.keys()`, `Object.values()`, `Object.entries()`
- `Object.keys(obj)`: ดึงรายชื่อ Key ทั้งหมดออกมาเป็น `string[]`
- `Object.values(obj)`: ดึงค่า Value ทั้งหมดออกมาเป็นอาเรย์

- ในโค้ดสมัยใหม่ นิยมใช้ **Object Spread `{ ...obj }`** มากกว่าเพราะสั้นกระชับกว่า

### 3.4 `structuredClone()`: การทำ Deep Clone ระดับ Native

## 6. หมวด Asynchronous: Promise Methods

เมื่อต้องเรียก API หลายตัวพร้อมกันใน Next.js หรือ NestJS การใช้ Promise Methods อย่างถูกวิธีจะช่วยลดเวลา Response Time ของระบบได้อย่างมหาศาล:

```
[ Sequential Fetching ] (ช้า)
Fetch A (1s) ──> Fetch B (1s) ──> Fetch C (1s)  Total = 3s

[ Promise.all Concurrent ] (เร็ว)
Fetch A (1s) ──┐
Fetch B (1s) ──┼──> Total = 1s!
Fetch C (1s) ──┘
```

### 6.1 `Promise.all()` vs `Promise.allSettled()`

| เมธอด | พฤติกรรมเมื่อมีตัวใดตัวหนึ่ง Error | เหมาะสำหรับ |
| :--- | :--- | :--- |
| **`Promise.all([p1, p2, p3])`** | **Fail-fast (Reject ทันที)** หากตัวใดตัวหนึ่งล้มเหลว จะทิ้งผลลัพธ์ของตัวอื่นทั้งหมด | ข้อมูลที่มีความเกี่ยวเนื่องกันสูง เช่น ดึงข้อมูล User + Order ที่ต้องใช้คู่กัน |
| **`Promise.allSettled([p1, p2, p3])`** | **รอจนจบครบทุกตัวเสมอ** ไม่ว่าจะ Success หรือ Error โดยส่งสถานะ `{ status: 'fulfilled', value }` หรือ `{ status: 'rejected', reason }` | การยิงงานที่ไม่ผูกมัดกัน เช่น ส่งแจ้งเตือน SMS + Email + Line Notify |

```typescript filename="promise-methods.ts"
// ยิงแจ้งเตือน 3 ช่องทางพร้อมกัน แม้ SMS จะล้มเหลว Email และ LINE ยังทำงานสำเร็จ
const results = await Promise.allSettled([
  sendEmailNotification(orderId),
  sendSmsNotification(orderId),
  sendLineNotify(orderId),
]);

results.forEach((res, index) => {
  if (res.status === "fulfilled") {
    console.log(`ช่องทางที่ ${index + 1} ส่งสำเร็จ`);
  } else {
    console.error(`ช่องทางที่ ${index + 1} ล้มเหลว:`, res.reason);
  }
});
```

## 8. ตัวอย่างโค้ด Pipeline จริง (Smart Butcher Data Pipeline)

ตัวอย่างการประกอบร่างของ `split`, `filter`, `map`, `reduce`, `new Set`, และ `Intl` เข้าด้วยกันเพื่อประมวลผลสรุปยอดขายเนื้อประจำวัน:

```typescript filename="src/services/reportPipeline.ts"
interface RawSaleRecord {
  recordId: string;
  rawPayload: string; // ข้อมูลดิบรูปแบบ: "SKU|MeatName|Category|Qty|PricePerUnit"
  soldAt: string;     // ISO timestamp
}

interface DailyCategorySummary {
  category: string;
  totalRevenue: number;
  totalQuantity: number;
  formattedRevenue: string;
}

export function processDailySalesData(records: RawSaleRecord[]): DailyCategorySummary[] {
  // 1. ตัวแปลงค่าเงินภาษาไทย
  const currencyFormatter = new Intl.NumberFormat("th-TH", {
    style: "currency",
    currency: "THB",
    maximumFractionDigits: 0,
  });

  // 2. ประมวลผลคลี่ข้อมูลดิบด้วย split และ map
  const parsedItems = records.map((record) => {
    const [sku, meatName, category, qtyStr, priceStr] = record.rawPayload.split("|");
    return {
      sku: sku.trim(),
      meatName: meatName.trim(),
      category: category.trim().toUpperCase(),
      quantity: Number.parseInt(qtyStr, 10),
      price: Number.parseFloat(priceStr),
    };
  });

  // 3. กรองเฉพาะรายการที่ถูกต้อง (quantity > 0)
  const validItems = parsedItems.filter((item) => item.quantity > 0 && !Number.isNaN(item.price));

  // 4. รวบรวมหมวดหมู่ทั้งหมดแบบไม่ซ้ำซ้อนด้วย Set
  const categories = [...new Set(validItems.map((item) => item.category))];

  // 5. จัดกลุ่มและคำนวณยอดรวมรายหมวดหมู่ด้วย reduce
  return categories.map((category) => {
    const categoryItems = validItems.filter((item) => item.category === category);
    
    const summary = categoryItems.reduce(
      (acc, item) => {
        acc.totalRevenue += item.price * item.quantity;
        acc.totalQuantity += item.quantity;
        return acc;
      },
      { totalRevenue: 0, totalQuantity: 0 }
    );

    return {
      category,
      totalRevenue: summary.totalRevenue,
      totalQuantity: summary.totalQuantity,
      formattedRevenue: currencyFormatter.format(summary.totalRevenue),
    };
  });
}
```

## 9. ข้อผิดพลาดที่พบบ่อย (Anti-patterns)

### ❌ ผิดพลาดที่ 1: เผลอใช้ `sort()` แก้ไขข้อมูลใน Props หรือ State ใน React
```typescript
// ❌ ผิด: sort() จะ mutate items เดิมโดยตรง ทำให้ React Re-render ผิดพลาด
function MeatList({ items }: { items: Product[] }) {
  const sorted = items.sort((a, b) => a.price - b.price); // อันตรายมาก!
  return <div>...</div>;
}

// ✅ ถูกต้อง: ใช้ toSorted() หรือทำ Shallow Copy ก่อนจัดเรียง
const sortedSafe = items.toSorted((a, b) => a.price - b.price);
// หรือ [...items].sort((a, b) => a.price - b.price);
```

### ❌ ผิดพลาดที่ 2: ใช้ `map()` โดยไม่มีการ Return ค่า (ทำงานแบบ Side-effect)
```typescript
// ❌ ผิด: map() ถูกสร้างมาเพื่อแปลงอาเรย์ หากต้องการรัน Side-effect ให้ใช้ forEach
orders.map((order) => {
  sendReceiptEmail(order.id); // สร้างอาเรย์ที่เต็มไปด้วย undefined โดยเปล่าประโยชน์
});

// ✅ ถูกต้อง: ใช้ forEach หรือ for...of
orders.forEach((order) => {
  sendReceiptEmail(order.id);
});
```

```typescript
const cart: CartItem[] = [];

// ❌ ผิด: เมื่อ cart เป็นอาเรย์ว่างเปล่า และไม่มี initial value เบราว์เซอร์จะโยน TypeError ทันที!
```

## 10. คำถามสัมภาษณ์งานระดับ Senior (Interview Q&A)

### Q1: ทำไมการใช้ `new Set()` ในการค้นหาข้อมูลขนาดใหญ่ จึงมีประสิทธิภาพสูงกว่า `Array.prototype.includes()` อย่างมีนัยสำคัญ?
**แนวทางคำตอบ:**
- `Array.prototype.includes()` ทำงานด้วยกลไก **Linear Search** โดยต้องวนตรวจสอบทีละตัวตั้งแต่ช่องแรกจนถึงช่องสุดท้าย มีความซับซ้อนเชิงเวลาเป็น **$O(n)$** หากอาเรย์มี 100,000 ชิ้นและค้นหา 1,000 ครั้ง จะเกิดการเปรียบเทียบข้อมูลสูงสุดถึง 100 ล้านครั้ง
- ขณะที่ `Set` ใน JavaScript Engine (เช่น V8) ถูกสร้างขึ้นบนโครงสร้างข้อมูล **Hash Table** ซึ่งจะนำค่า Key ไปผ่าน Hash Function เพื่อคำนวณตำแหน่ง Bucket ของหน่วยความจำโดยตรง ทำให้การตรวจสอบ `set.has(val)` มีความซับซ้อนเชิงเวลาเฉลี่ยคงที่เพียง **$O(1)$** ไม่ว่าข้อมูลใน Set จะมีขนาด 10 หรือ 100,000 รายการ เวลาในการค้นหาก็จะเร็วเท่าเดิม

### Q2: ในการคัดลอกอ็อบเจกต์ที่มีความซับซ้อน (Nested Objects) ทำไมคำสั่ง `structuredClone()` จึงถูกสร้างขึ้นมาแทนที่ `JSON.parse(JSON.stringify(obj))`?
**แนวทางคำตอบ:**
เพราะเทคนิค `JSON.parse(JSON.stringify(obj))` มีข้อจำกัดร้ายแรงหลายประการ:
1. แปลงอ็อบเจกต์ชนิด `Date` ให้กลายเป็น `string` ISO และสูญเสีย Prototype Methods ไปทั้งหมด
2. ไม่รองรับ `Set` และ `Map` (จะถูกแปลงเป็น `{}` ว่างเปล่า)
3. ค่าฟิลด์ที่เป็น `undefined`, `Symbol`, หรือ Function จะถูกลบทิ้งไปโดยอัตโนมัติ
4. โยนข้อยกเว้นทันทีหากมี **Circular Reference** (การอ้างอิงวนลูปหากัน)
5. `structuredClone()` รองรับการโคลน Typed Arrays, RegExp, ArrayBuffer, Date, Set, Map, และ Circular Reference ได้อย่างสมบูรณ์แบบที่ระดับ Native C++ ของเอนจิน
