## 1. คืออะไร / ใช้ทำไม

**Environment Variables** คือการจัดการตัวแปรสภาพแวดล้อมเพื่อแยกการตั้งค่าระหว่างเครื่อง Local และเซิร์ฟเวอร์จริง รวมถึงป้องกันไม่ให้ Secret Key (เช่น รหัสผ่านฐานข้อมูล, API Key ลับ) รั่วไหลไปยังเบราว์เซอร์ โดยจำแนกตามคำนำหน้า **`NEXT_PUBLIC_`**

ช่วยรักษาความลับของระบบและทำให้แอปพลิเคชันมีความปลอดภัยตามหลัก Twelve-Factor App

## 2. ตัวอย่างโค้ด (TypeScript)

### การตั้งค่าในไฟล์ `.env.local`

```env filename=".env.local"
# Server-only: เข้าถึงได้เฉพาะบนเซิร์ฟเวอร์เท่านั้น (ปลอดภัย 100%)
DATABASE_URL="postgresql://user:pass@localhost:5432/scripture_db"
JWT_SECRET="super-secret-key-that-never-goes-to-client"

# Client-accessible: บันเดิลส่งไปยังเบราว์เซอร์ได้
NEXT_PUBLIC_APP_URL="https://scripture.app"
NEXT_PUBLIC_GA_ID="G-XXXXXXXXXX"
```

### การตรวจสอบตัวแปรด้วย Zod (Type-safe Environment)

```typescript filename="src/lib/env.ts"
import { z } from 'zod';

const envSchema = z.object({
  DATABASE_URL: z.string().url('DATABASE_URL ต้องเป็น URL ที่ถูกต้อง'),
  JWT_SECRET: z.string().min(16, 'JWT_SECRET ต้องมีความยาวอย่างน้อย 16 ตัวอักษร'),
  NEXT_PUBLIC_APP_URL: z.string().url(),
});

// จะโยน Error ทันทีตอนเริ่มรันแอปหากตัวแปรสภาพแวดล้อมไม่ครบถ้วน
export const env = envSchema.parse(process.env);
```

## 3. ควรใช้เมื่อไหร่ / ไม่ควรใช้เมื่อไหร่

- **ไม่มีคำนำหน้า**: ใช้กับ Credentials, API Secret Keys, Private Encryption Keys (อ่านได้ใน Server Components, Actions, Route Handlers)
- **`NEXT_PUBLIC_`**: ใช้เฉพาะค่าที่ทุกคนสามารถรู้ได้ เช่น โดเมนของระบบ, รหัส Google Analytics, Theme Key
- *ห้ามใช้*: `NEXT_PUBLIC_` กับรหัสผ่านหรือ Secret Keys ใดๆ ทั้งสิ้น

## 4. ข้อควรระวัง

<Callout type="danger" title="NEXT_PUBLIC_ ถูกฝังลงใน Bundle">
ตัวแปรที่ขึ้นต้นด้วย `NEXT_PUBLIC_` จะถูกแปลงเป็นสตริงคงที่และฝังเข้าไปในไฟล์ JavaScript ทันทีตอน Build ทุกคนสามารถกด F12 Inspect ดูได้ ห้ามใส่ API Secret เด็ดขาด
</Callout>

<Callout type="tip" title="ใส่ .env*.local ลงใน .gitignore">
ตรวจสอบให้แน่ใจเสมอว่าไฟล์ `.env.local` และ `.env.production.local` ถูกเพิ่มไว้ใน `.gitignore` เรียบร้อยแล้ว เพื่อไม่ให้เผลอคอมมิตรหัสผ่านขึ้น GitHub
</Callout>
